# HTML Elements Practice

Class exercises from December 2023 covering the core HTML elements and basic CSS.

| File | What it covers |
|------|----------------|
| `INDEX2.html` + `style.css` | Headings, paragraphs and `<br>`, internal vs external CSS |
| `INDEX2-MANOLO.html` + `style-MANOLO.css` | Ordered lists, tables, links, images, ids and a styled box |

## Run

Open either HTML file in a browser.

> `INDEX2-MANOLO.html` links `style.css`. To see its own styles, change the link to `style-MANOLO.css`. Its image and link also point at paths on my old Windows machine.
